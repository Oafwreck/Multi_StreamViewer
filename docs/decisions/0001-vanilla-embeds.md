# 0001: 公式iframeをVanilla HTMLで扱う

- 日付: 2026-08-02
- 状態: 採用

## 判断

最小版はTwitch / YouTubeの公式埋め込みURLを使い、APIキーとビルド依存を持たないVanilla HTML / CSS / JavaScriptとする。

## 理由

- Windowsでローカルサーバーを起動すればすぐ試せる。
- URL解析、状態、表示を分離し、今後API検索や並べ替えを追加しやすい。
- 認証情報を扱わずに最小機能を検証できる。

## 影響

- オンライン接続が必要。
- 埋め込み可否、広告、チャット表示は各サービス側の制約を受ける。
- `file://`ではなくHTTPサーバー起動を推奨する。
