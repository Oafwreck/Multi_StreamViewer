# PROJECT

## 目的

複数のTwitch / YouTube配信を1画面で追い、注目中の1配信だけチャットを読む。

## ユーザーがすること

配信URLまたはチャンネル名を追加し、最大8画面を見ながらチャット対象を切り替える。

## 基本の流れ

追加 → マルチビュー表示 → 配信を選択 → 右側チャット更新 → 不要な配信を削除。

## 今回作る最小機能

- Twitchチャンネル / URLとYouTube URLの解析
- 最大8画面の自動グリッド
- 選択中配信のチャット表示
- チャット表示切替、配信削除とUndo
- ローカル保存
- 読込、空、入力エラー、埋め込み遅延の状態表示

## 今回は作らない機能

- アカウント、クラウド同期、配信検索
- Twitch / YouTube API連携
- 音量の一括制御、レイアウト手動編集
- モバイル専用UI

## 主要画面

上部の追加フォーム、中央の配信グリッド、右側の選択中チャット。

## 成功条件

- 8件まで追加でき、9件目を拒否する。
- 配信選択で映像iframeを再読込せず、チャットだけ切り替わる。
- 再読込後も配信一覧と選択状態が復元される。

## 未決定事項

- レイアウトの手動並べ替え
- 配信セットの複数保存
- YouTube通常動画でチャット非対応時の詳細検知
